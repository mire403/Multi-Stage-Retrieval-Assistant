# Multi-Stage-Retrieval-Assistant
LayeredRetriever（层级检索助手）是一个多阶段、可解释的认知检索系统，模拟人类专家逐步收敛问题空间的过程。 与传统 RAG 不同，系统采用三阶段架构：Stage 1 广泛检索（高召回，50-200 个候选）、Stage 2 语义精炼（高精度，5-10 个精选）、Stage 3 答案合成（生成答案并标注引用）。 系统首先分析查询意图和关键概念，生成执行计划；随后通过向量检索、关键词检索和元数据过滤的混合策略收集候选；再使用交叉编码器重排序、子问题分解和 LLM 相关性判断进行精炼；最后基于精选上下文生成答案，并输出引用和置信度。 支持 dry-run 调试、完整执行轨迹追踪、各阶段独立替换测试，以及灵活配置。适用于学术研究、企业知识库、客户支持等场景。
